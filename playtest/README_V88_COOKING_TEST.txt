BỎ PHỐ VỀ QUÊ v88.14.0 — COOKING STATION 2.0 (BẢN GAME TEST)

1. Giải nén ZIP vào THƯ MỤC MỚI, giữ nguyên index.html, js, css và assets.
2. Mở index.html bằng Chrome / Edge. Nếu có tính năng bị chặn file://, dùng HTTP local server / Cloudflare Pages.
3. Tạo tài khoản TEST riêng, chọn nghề và bấm MỞ QUÁN.
4. Khi có khách, khu BẾP CÓ HỒN xuất hiện thay trạm chế biến cũ:
   - TRÀ SỮA: chọn ly/cốt/topping/đường/đá -> chạm rót -> chạm dừng khi ~72% -> chạm lắc 3 lần -> giao.
   - MÌ CAY: chọn thố/nước cốt/topping/cấp cay -> chạm bắt đầu -> tăng lửa để giữ 58-82% trong ~1 giây -> giao.
   - XIÊN QUE: chọn khay/xiên/sốt -> bắt đầu nướng -> lật/quét sốt -> vớt khi chín 65-90% -> giao.
5. Giá bán có nút +/-5 Xu, lãi dự kiến hiển thị ngay trên bàn.
6. Thử trên điện thoại DỌC, ưu tiên 320/375/390/430px. Không đổi nghề giữa chừng trừ trong màn chơi mới.
7. Bản này giữ logic tính tiền/đơn/kho của game gốc; điểm DẤU ẤN là CHỈ SỐ HIỂN THỊ, chưa thêm thưởng.
8. Chưa thêm hình công trình B1-B9; hình Sân Quán B1 hiện vẫn là QA Draft 5 (chưa art approval).
9. Save cũ chưa được dùng để nghiệm thu trên máy thật; hãy sao lưu và dùng hồ sơ test.
10. Main GitHub không đổi; đây là build thử từ nhánh feat/v88-phone-os-core.
